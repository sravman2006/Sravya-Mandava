2026 to present AIM-HI Lab, Cleveland Clinic Urology Institute

Clinical NLP for kidney cancer recurrence and metastasis

Abstract accepted for presentation at the Society of Urological Oncology (SUO) 2026

  • Built an automated pipeline that identifies local recurrence, metastatic disease at diagnosis, and metastatic progression after treatment, using the health records of 110 nephrectomy patients.
  • Used a Qwen 3.5-9B large language model to combine information from longitudinal radiology, urology, medical oncology, radiation oncology, pathology, and operative notes.
  • Designed structured prompts and branching logic to guide extraction across very different kinds of documentation.
  • Converted free-text model responses into standardized clinical labels with deterministic rule-based post-processing.
  • Compared automated classifications with independent manual annotations and measured performance with agreement and F1 scores.
  • Clinical NLP
  • LLMs (Qwen)
  • EHR data
  • F1 and agreement metrics
2025 to 2026 Personal project

Cardiovascular disease risk prediction

About 92% overall accuracy on 300,000+ health records. View the code on GitHub

  • Trained a Random Forest classifier to predict cardiovascular disease risk from demographic, lifestyle, biometric, and medical-history features.
  • Engineered predictive variables and built the full workflow of preprocessing, training, validation, and evaluation in Python and Scikit-learn.
  • Looked beyond accuracy to precision and recall, and documented the main limit: the data is imbalanced, so the model catches too few high-risk cases. Improving that recall is the next step.
  • Saved the trained model with Joblib so results are reproducible and the model can be deployed.
  • Python
  • Scikit-learn
  • Random Forest
  • Joblib
